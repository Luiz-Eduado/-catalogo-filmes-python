# Catálogo de Filmes em Python

Projeto acadêmico desenvolvido em Python com SQLite para gerenciamento de um catálogo de filmes.

## Funcionalidades

- Cadastro de filmes
- Listagem ordenada por título
- Busca por gênero
- Remoção de filmes
- Persistência dos dados em banco SQLite
- Validação da nota entre 0 e 10

## Tecnologias

- Python 3
- SQLite
- SQL

## Estrutura

- `main.py` — aplicação principal e operações CRUD
- `script.sql` — estrutura e dados iniciais do banco
- `banco.db` — banco SQLite utilizado pelo projeto

## Como executar

1. Instale o Python 3.
2. Execute:

```bash
python main.py
```

O arquivo `banco.db` será criado automaticamente caso não exista.

## Conceitos utilizados

O projeto utiliza funções, estruturas de repetição e decisão, tratamento de exceções, SQL, SQLite, consultas parametrizadas e operações CRUD.
